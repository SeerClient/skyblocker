# GAPS - burn-down batch J

Genuine gaps found while replacing the converter's placeholders in batch J's packages. Each was checked against
`RustSrc` (or the external library's source) before it was written down. Every site is marked `// rust: port gap`
(or `// rust: blocked` for a cross-package block) in the file, and the `todo!` is kept only where the statement
cannot be written at all.

Kind: **game** = a `RustSrc` item is private or missing; **library** = an external Java library the mod bundles has
no Rust port (a whole subsystem); **cross-package** = the blocker is in a mod file no batch-J package owns.
