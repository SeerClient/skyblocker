# GAPS - batch B (`skyblock/dungeon/`, `skyblock/item/`)

Things the game crate (RustSrc) or the mod runtime does not provide, found while fixing the batch B compile
errors. RustSrc was NOT edited. Every RustSrc row was checked by grepping RustSrc for the member. Sites are
marked in the source with `rust: port gap` where a statement had to give way; elsewhere the converter's
`TODO(fabric2seer)` remains on the dependent code.
